# Smart-Job-Portal-System
The Smart Job Portal System is a web-based application developed using Python, Streamlit, and MySQL to simplify the recruitment process for both job seekers and administrators. The system allows users to register, search for jobs based on their skills and preferred location, apply for suitable job opportunities, and track their application status in real time.

The application includes a secure Admin Panel where administrators can post new job vacancies, manage job listings, and update application statuses such as Applied, Shortlisted, Interview Scheduled, Selected, and Rejected. The backend uses a MySQL relational database to store user details, job information, and application records efficiently, while Streamlit provides a clean and user-friendly interface.

This project demonstrates the practical implementation of Database Management System (DBMS) concepts, including relational database design, SQL queries, CRUD operations, and database connectivity. It was developed as an academic project to showcase a modern, secure, and efficient online job recruitment platform.
